API Keys (Optional)

KeyRequired?SourcePurpose
GEMINI_API_KEY Optional Google AI Studio AI chatbot explanations for fake documents
ℹ️ Note: The core document screening (Aadhaar, PAN Card, Passport, Voter ID classification) works fully without a Gemini API key. The key is only needed for the AI Security Assistant chatbot that explains why a document was flagged as fake.

Configuring the API Key

  1. Navigate to server/.env
  2. Replace the placeholder: GEMINI_API_KEY=your_actual_api_key_here
  3. Restart the backend server
